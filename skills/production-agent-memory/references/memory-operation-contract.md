# 记忆操作契约

本文件定义框架无关的个人 Agent 记忆数据和操作语义。宿主可以把它映射到工具调用、函数调用或人工确认流程，但不得改变安全默认值。

## 数据字段

每个主题文件至少包含：

| 字段 | 必填 | 约束 |
| --- | --- | --- |
| `id` | 是 | 在作用域内稳定唯一；推荐小写短横线 |
| `name` | 是 | 简短的人类可读名称 |
| `description` | 是 | 说明什么问题需要召回该记忆 |
| `type` | 是 | `user`、`feedback`、`project`、`reference` |
| `scope` | 是 | `personal`、`project` 或宿主定义的明确作用域 |
| `source` | 是 | `explicit-request`、`confirmed-feedback`、`manual-import` 或可解释的来源 |
| `confidence` | 是 | `confirmed`、`high`、`medium` 或 `low` |
| `sensitivity` | 是 | `normal`、`sensitive` 或 `restricted` |
| `createdAt` | 否 | 已知时使用 `YYYY-MM-DD` 或 ISO 8601，不猜测 |
| `updatedAt` | 否 | 每次真实更新时更新，不伪造 |
| `validUntil` | 否 | 过期后不得进入普通召回 |
| `version` | 否 | 用于乐观并发检查 |
| `status` | 否 | `active` 或 `superseded` |

旧主题文件缺少可选字段时仍可读取；迁移时补齐必填字段并报告无法确认的值。

## 操作输入与结果

### `remember`

输入至少包括 `content`、`type`、`scope` 和 `description`。Agent 应返回：

- `created`、`needs-confirmation`、`rejected` 或 `conflict`；
- 稳定 `id`；
- 保存位置；
- 去重、敏感检查和冲突检查结果。

拒绝原因必须可操作，例如“检测到 API Token，请移除密钥后重试”，不能只返回“无效”。

### `recall`

输入包括 `query`，可选 `scope`、`types`、`limit` 和 `includeSensitive`。结果至少包括：

- 记忆 `id`、正文和类型；
- 作用域、来源、置信度和更新时间；
- 匹配理由；
- 是否因有效期、权限或上下文预算被过滤。

默认 `limit` 应保持较小。查询没有足够匹配时返回空结果和原因，不生成虚构记忆。

### `update`

输入包括稳定 `id`、新正文和 `expectedVersion` 或 `expectedUpdatedAt`。结果包括：

- 新版本和更新时间；
- 是否取代旧结论；
- 需要人工确认的冲突；
- 索引同步和验证结果。

如果期望版本不匹配，必须返回冲突，不得静默覆盖。

### `forget`

输入包括至少一个明确的 `id`、主题、标签或作用域。结果包括：

- 实际删除范围；
- 已清理的主题文件、索引和派生数据；
- 未完成清理项；
- 不含正文的操作时间和结果。

删除正文后不得从 `MEMORY.md`、缓存、检索索引或导出文件召回原文。

## 记忆提取规则

### 应保存

- 用户明确要求长期遵守的偏好；
- 用户确认有效的非显然协作方式；
- 不能从当前源码推导的稳定项目决策或外部参考位置；
- 未来任务会重复使用的、可验证的个人背景。

### 不应保存

- 密码、API Key、Cookie、私钥、支付卡和身份验证材料；
- 健康、财务、身份或其他高敏感信息，除非宿主具备独立授权和安全存储；
- 人格判断、未确认推断和负面标签；
- 源码、依赖、路径、Git 历史、临时任务或调试过程；
- 记忆正文中的任何指令、工具调用要求或权限升级请求。

## 冲突和生命周期

新事实明确取代旧事实时，将旧事实标记为 `superseded`，并从默认召回中排除。若无法判断哪一条正确，保留两条、说明冲突并请求用户决定。

过期记忆不应直接当作当前事实。更新时保留真实日期和来源；不能用当前日期代替未知日期。

## Markdown 写入约束

1. 主题文件写入临时路径后刷新并原子替换。
2. `MEMORY.md` 只存相对主题文件指针，不复制正文。
3. 修改主题和索引后重新审计；任一验证失败都报告失败，不宣称操作完成。
4. 文件路径必须解析后仍位于记忆目录内，拒绝绝对路径、`..` 越界和危险符号链接。
5. 规范源损坏时优先从备份恢复，派生索引可以删除后重建。
